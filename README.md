# Steam Linux Compatibility Checker

Lokales Python-Tool zur Analyse der Linux-/Proton-Kompatibilität einer Steam-Bibliothek.

## Ziele

- Steam-Bibliothek automatisch erkennen
- AppIDs und Spielenamen erfassen
- Linux-/Proton-Kompatibilität über verschiedene Provider bewerten
- HTML-, CSV- und JSON-Reports erzeugen
- Änderungen zwischen Prüfungen erkennen

## Sicherheit

Version 1 arbeitet ausschließlich read-only gegenüber Steam.
